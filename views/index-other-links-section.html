Other Mii Resources

You may like these other Mii creations. If you want me to shout out another project, ask me and I will add it if I think it's cool.

  • Mii Creator by kat21 - Web app for editing Miis, making pose images with them, and more.
    • This site is more feature-dense, so give this a try if it's what you're looking for. See the official video as well.
    • (As of writing the credits are WIP, so) It is made with prior contributions from me:
      • Two Mii rendering solutions, Wii U/Miitomo shaders and Switch LUTs, documenting accurate body scaling
      • Code for reading Mii shapes/textures in JS and loading into Three.js
      • Data parsing: struct-fu port, FFSD format, QR en/decoding
      • Initial inspiration, various help and debugging in the beginning, clothing idea (read HTML comments for all details)
    • Note: As of writing (January 2026), mandatory Discord membership is still required: https://discord.gg/miicreator
  • My JSFiddles - I write a lot of Mii-related code snippets for: converting Tomodachi Collection DS Mii data, accurately rendering Miis in JS, en/decoding Mii QRs with game extra data, Mii conversion code, a Switch Mii color reference... Occasionally more is added.

See Even More Resources

Sorry if I didn't put your favorite tool above, I didn't want to add an endless amount to scroll through. I'm prioritizing what I think is coolest and most recent. Here is more to explore:

  • FFLResource.py extractor - Originally by Abood, this tool exports and import shapes and textures from FFL resources, and my fork can also do AFL/Miitomo resources. Use this instead of mii-assets by jaames as it extracts more data.
  • PF2M Mii Renderer - It uses the official Mii Studio API that may provide a little bit more accuracy and reliability, and it doesn't need self-hosting.
    • Resources to interface with Mii Studio: mii-js by Jon Pretendo (TypeScript), mii2studio (Python), and WiiLink's Studio conversion in Go
    • Note that my API is (mostly) compatible with Mii Studio as well.
  • My Avatar Editor (WiiLink archive) - Old Wii-era Flash Mii editor. Works offline and on old devices, but kinda sucks. The .mae files are same as .rcd and work here.
  • HEYimHeroic's Mii Library and MiiDataFiles - Resources for Miis in various consoles, games, etc., in many formats.
  • MiiPort - Lets you import and export Miis from a homebrewed Switch.
    • The code is the best source currently for Switch, 3DS/Wii U Mii structures and Switch color conversion tables.
  • MiiInfoEditorCTR - Can edit fields in your 3DS/Wii U Mii data.
    • Other tools by Kazuki: Mii-Importer, Mii-Dumper for 3DS databases.
  • Mii Blender resources: Mii2U Blender Mii Maker, pvr-model-extractor by jaames/PicelBoi fork, Yodakiller3000 Miitomo rip tutorial
    • Note that I haven't used most of these. I just hope they will be helpful.
